# Handcali
The dataset of robot hand-eye calibration
The images captured by the ABB IRB1100 can be utilized for hand-eye calibration. We have provided HandCali with 40 images, which are sequentially numbered from 1 to 40. The Hand-eye data.xlsx contains the robot end-effector pose data, which are corresponding to each image. q1, q2, q3, q4, q5, and q6 represent the joint angles of the robot.
